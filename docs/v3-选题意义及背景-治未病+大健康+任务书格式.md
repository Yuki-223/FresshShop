# 一、选题背景及意义

随着《"健康中国 2030"规划纲要》将"预防为主"确立为基本方针，大健康产业迅速发展，2025 年市场规模已达约 10 万亿元。保健品与功能性食品作为"治未病"理念在日常消费中的主要载体，市场体量持续扩大，中国市场已达约 2,600 亿元。与此同时，消费主体正经历代际更替，年轻群体逐渐成为主力，其健康需求高度细分化，购买渠道也从线下药店大规模转向线上电商。然而，普通消费者普遍缺乏营养学专业知识，面对品类繁多的保健品时极易陷入选择过载与决策瘫痪——知识缺口与选择过载相互放大，而线上电商场景中又缺少过去药店店员所承担的"一对一导购"角色。传统推荐算法依赖大量用户行为数据且推荐过程不透明，难以满足保健品消费对个性化和可解释性的双重要求。近年来大语言模型技术的快速发展，为构建对话式智能导购系统提供了新的技术路径。本课题旨在设计并实现一个融合大语言模型的保健品垂直电商平台，通过对话式交互帮助消费者表达健康需求、缩小决策空间，并借助用户记忆机制实现个性化的持续服务，探索大语言模型在健康消费领域辅助决策的应用模式与效果。

# 二、主要研究内容

本课题要求围绕保健品消费中的决策困境，完成以下研究工作：首先，对保健品电商领域的消费者行为进行分析，梳理选择过载与知识缺口对购买决策的影响机制，明确系统需要解决的核心问题。在此基础上，设计并实现一个保健品垂直电商平台，涵盖商品展示、分类筛选、购物车、订阅购买、下单结账及用户评价等完整购物功能，搭建可供导购系统调用的商品知识库。其次，研究基于大语言模型的对话式导购方案，使消费者能够以自然语言描述自身健康状况与需求，由系统理解意图、匹配商品知识库并生成附带理由的推荐结果，重点解决推荐的可解释性问题。进而，设计用户记忆机制，从对话中提取用户的健康关注点、过敏信息、历史购买及使用反馈等关键信息，构建并持久化个人健康画像，使系统在后续交互中能基于已有了解提供更精准的建议。最后，对系统进行测试与效果评估，验证完整购物流程的可用性，考察对话式导购对缩小消费者决策空间的实际效果，并对比有记忆与无记忆条件下的推荐质量差异。
