# FresshShop backend (Medusa 2.22)

Copied from `Yuki-223/shopStore` (`medusa-dtc/apps/backend`, the official Medusa DTC starter with the shopStore
changes: 5 MB body limit for `POST /admin/products` and the product search index). From here on this copy is
developed independently — shopStore is only used as the source of the collected Metagenics data.

## Run locally

Requires Node.js ≥ 22.23 and pnpm 10.

```bash
cd backend
pnpm install
pnpm setup:local   # embedded PostgreSQL in .local/, migrations, admin user
pnpm start:local   # PostgreSQL + Medusa → http://localhost:9000/app
```

- The database lives in `backend/.local/postgres` (port 55433), secrets and the admin login in
  `backend/.local/config.json`. Both are git-ignored.
- `.env` is generated by `pnpm setup:local`. CORS allows the storefront on `http://localhost:3000`.
- Running as root (cloud containers) is handled automatically: PostgreSQL runs as the `postgres` user.
